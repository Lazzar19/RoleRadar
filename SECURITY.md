# Security

## Reporting a vulnerability

Do not open a public issue for security problems.

Use [GitHub Security Advisories](https://github.com/Lazzar19/RoleRadar/security/advisories/new) for this repository, or contact the maintainer privately if advisories are not available.

Include steps to reproduce, impact, and any suggested fix.

## Scope

RoleRadar is a single-user, self-hosted service. Treat `.env`, database dumps, `MAILBOX_URL`, `LLM_API_KEY`, and `TELEGRAM_TOKEN` as secrets. Default Compose credentials are for local development only.
